# Skill de Exemplo em Português

Esta é uma skill de exemplo para a comunidade **Hermes Brasil**. Use como modelo ao criar suas skills.

## Quando usar
- Criar uma nova skill para o repositório
- Entender o formato padrão de skills
- Começar uma contribuição

## Formato (frontmatter)

Toda skill começa com um bloco `frontmatter`:

```markdown
---
name: nome-da-skill
description: O que a skill faz. A PRIMEIRA FRASE é o gatilho de uso (use quando...).
---
```

## Estrutura recomendada

```
# Título da skill

## Quando usar
(quando ativar esta skill)

## Passo a passo
1. Primeiro passo
2. Segundo passo
3. ...

## Dicas
- Dica 1
- Dica 2

## Erros comuns
- Problema e solução
```

## Boas práticas

- Descrição curta e acionável (primeira frase = gatilho)
- Passos numerados e exatos
- Inclua comandos quando útil
- Adicione seção de erros comuns
- Escreva em português (comando técnicos podem ficar em inglês)

## Verificação

- Teste a skill antes de contribuir
- Confirme que o frontmatter está correto
- Verifique que funciona de forma reprodutível
