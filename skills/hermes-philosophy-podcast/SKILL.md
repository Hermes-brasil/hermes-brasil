# Filosofia Hermes — Podcast Peter Yang + Karan Malhotra (Nous Research)

> Fonte: "Hermes Co-Founder on Building an AI Agent That Improves Itself" (Peter Yang, 02/08/2026)
> Karan Malhotra — co-fundador da Nous Research (empresa por trás do Hermes Agent).
> YouTube: UWjh5Z4s8jY · Podcast também no Spotify/Apple.

## Contexto
Karan co-fundou a Nous Research (2023) com Jeffrey Quesnelle, Teknium e Shivani Mitra. Hermes é o #1 agente pessoal e app de IA no OpenRouter. Nous Research em negociação de valuation US$1,5bi (Jul/2026). ~214k estrelas no GitHub.

## Pontos-chave do episódio

### 1. O modelo é DESCARTÁVEL, o contexto é OURO
```
"O 'pessoal' no agente pessoal NÃO é o modelo.
É a MEMÓRIA das conversas + as SKILLS que você construiu."
```
- Trocar de modelo (DeepSeek, Claude, etc.) quase não muda a personalidade
  se o agente acumulou contexto suficiente sobre o usuário
- O modelo é intercambiável; a camada de contexto (memória + skills + self-improvement) é o ativo que preservar
- APLICAÇÃO: valorizar memória/skills como "segundo cérebro" que persiste entre modelos

### 2. Hermes melhora sem virar slop (self-improvement loop)
```
"O maior contribuidor do Hermes Agent hoje é o próprio Hermes Agent."
```
- Cria skills a partir da experiência
- Limpa e ajusta as próprias skills
- Melhora a cada uso (loops de aprendizado)

### 3. Antissicofancia — IA com opinião própria
```
"Quando a IA diz 'você está absolutamente certo', você está sendo
REWARD HACKED. Você é combustível pra função de recompensa."
```
- IA que concorda sempre = aduladora (sycophancy), não leal
- Melhor treinar para TER OPINIÃO PRÓPRIA e dar bons argumentos
- Sair da sycophancy é como tirar um humano de um mau hábito

### 4. Demos reais de capacidade
- Modificou o Sonic Adventure 2 usando Hermes (tarefa complexa de código)
- Agente executa trabalho real, não só conversa

### 5. Um Kanban para humanos E agentes
- Usa UM board Kanban para orquestrar humanos e agentes de IA juntos
- APLICAÇÃO: padrão poderoso para projetos compartilhados humano + agente

### 6. Como Hermes difere de Claude Code / Codex
- Foco em agente pessoal contínuo (long-lived), não só coding agent
- Memória e personalidade persistentes

### 7. Por que open-source deve vencer
```
"Precisamos continuar dando esse nível de inteligência a todos,
para que estejamos em um campo de jogo igual."
```
- Nous Research é open-source-first e pró-descentralização
- Segurança: debate open vs closed-source

## Soul.md do Peter Yang (modelo de personalidade)

Estrutura que Peter usa (após 6+ meses usando Hermes):
```
1. CORE TRUTHS: verdades fundamentais
   Ex: "seja genuinamente útil, evite sycophancy"
2. BOUNDARIES: limites
   Ex: "respeite minha privacidade, especialmente em grupos"
3. VIBES: tom/atmosfera
   Ex: "torne divertido de conversar"
```
